## 起价之外的账单：托管行业最常见的六种隐藏费用

托管的实际月费几乎从来不只等于机位费，这是这个行业的通病，也是多数入门文章不讲清楚的地方。第三方整理里列出的常见加价项有六类：

1. **电力超量附加费**。托管计费的核心是电力，市场上常见的计费方式是“固定电力额度+超量罚款”或按表计费直通。一台典型 1U 服务器功耗 200–400W，装满的机柜能拉 3–5kW，高密度 GPU 机柜甚至要 10–20kW。Sharktech 两档套餐给的电力范围（1–6U 200–1200W、10–42U 1600–5500W）意味着你报配置时要对设备实际功耗心里有数。
2. **高级带宽档**。300TB 起的流量对多数业务够用，但大流量业务超出部分的计费标准官网没有公示，必须问销售。
3. **安装/上架费**。官方门户里这是报价项之一，下单前核对。
4. **cross-connect 费**。接特定运营商的交叉连接通常单独收费，Sharktech 支持按需指定 cross-connect，费用要在配置报价里确认。
5. **IP 分配费**。超出小 /29 规模的 IP 通常加价。
6. **非工作时间支持和远程代操作（remote hands）**。Sharktech 提供 24/7 现场技术支持处理紧急情况，但 remote-hands 的工作范围（比如换硬盘、重启这类操作）需要和团队提前协商约定。

官方页面对订购流程的描述也印证了这套逻辑：先在客户门户里选空间和位置，然后核对电力、连接、安装费和远程代操作费用，再下单；机笼或定制部署走逐项报价。换句话说，这家透明度算高的，但“透明”的前提是你把配置清单填完整。

## 主机托管、租独立服务器还是云服务器：按持有硬件的时间和数量决定

三种方式花的是三种钱。租独立服务器是连硬件一起租，坏件归服务商修；云服务器按资源计费，弹性最大、单价最贵；主机托管是硬件你买、机房收场地和服务费，坏件也得自己扛。

判断标准可以量化。如果你需要三台高配服务器长期跑业务，买硬件的一次性投入之后，托管月费可能只要一两百美元（芝加哥整柜 $280 起能放下不少设备），而租三台同类配置每月动辄数百美元，两三年累计就是一台新机器的钱。反过来，只放一台入门服务器、或者业务量波动大随时可能退场，租服务器或云服务器更划算——托管省的钱要靠“硬件用得够久”才赚得回来。另外托管需要你自己准备备件或和机房协商维修方式，这对硬件故障容忍度有要求，下单前想清楚。

还有一类需求托管解决得最干脆：数据驻留和配置自由。需要硬件留在特定地区（比如欧盟），或者要自己控制整机配置、装自己的网络设备，托管几乎是唯一选择。不确定自己适不适合托管的话，👉 [先用 Sharktech 的托管门户模拟配置一遍，看看月费是否符合预期](https://bit.ly/SharKtech)，配置不合适再退回来租服务器也不迟。

一台。1–6U 档就是为单台或少量设备设计的，一台 1U 服务器也能托管，后续扩容再加 U 位。

**机房坏了有人管吗？**
机房侧的基础设施（电力、制冷、网络）是完全冗余设计，官网整体宣传中提到 99.99% 正常运行时间，但托管服务页本身未附具体 SLA 条款，把它当参考值而非合同承诺比较稳妥。你的硬件故障由 24/7 现场工程师协助处理，具体代操作范围要提前和团队约定。

**有合同锁定吗？**
官网按月计价，未公示最低合同期；机柜和机笼级别的定制方案可能涉及合同条款，询价时直接问清。前六个月的 10% 折扣（如销售确认存在）对应的就是“新合同”，说明合同条款确实因方案而异。
